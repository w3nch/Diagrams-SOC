# Blue Team SOC Diagram Collection

This repository contains a collection of diagrams created using [draw.io](https://draw.io/) for blue team operations and security operations center (SOC) workflows. These diagrams were developed as part of the **30-Day SOC Challenge**, **SOC Automation planning**, and related exercises.

## 📁 Contents

| File Name                          | Description                                                                 |
|-----------------------------------|-----------------------------------------------------------------------------|
| `30 day soc challenge.drawio`     | A high-level overview and daily plan for a 30-day hands-on SOC challenge.  |
| `Honey pot.drawio`                | Architecture and deployment diagram for honeypot setup within the SOC lab. |
| `SOC-Automation-Project.drawio`   | Process flow and tooling diagram for automating SOC tasks and alert triage.|

## 📌 Use Cases

- Security team training and onboarding
- Reference architecture for internal SOC design
- Planning documentation for blue team projects
- Visualizing detection and response workflows
